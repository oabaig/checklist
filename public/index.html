    Keyboard shortcuts
    N or /Go to the "Add an item" box
    EscLeave the text box
    ↑ / ↓Move between items
    Space or EnterCheck or uncheck the focused item
    Delete or BackspaceDelete the focused item
    Ctrl/Cmd + DDelete the last added item in this list
    [ / ]Previous / next list
    ← / →Previous / next list (when a tab is focused)
    TNew list
    R or F2Rename this list (Enter saves, Esc cancels)
    ?Show or hide this help
